# 項目用XDWの形式

見本はPDF・XDWの表示ページを300dpiで画像化し、同じページ寸法・回転0度の画像XDWを新たに作成します。元の注釈は背景画像に含まれ、編集可能な注釈として引き継ぎません。画像XDW生成後、注釈が0個であることを読み取り直して確認してから、全文OCRの各領域へ赤い無塗り矩形を配置します。

Viewerで不要な矩形を削除し、値欄に合わせて移動・拡縮し、必要なら新しい四角形を追加して保存してください。四角形はページへ直接置いてください。グループ・付箋の内部にある矩形には対応しません。初期配置する矩形の最小幅・高さは各3mmです。OCR領域が小さい場合は周囲へ広げ、ページ端では内側へ収めます。

分割時は編集用XDWを保持し、残った矩形ごとに他の矩形だけを削除した新しいXDWを作成します。初期名は`項目_001.xdw`などです。保存後の矩形とページ寸法を再読取り確認し、すべて成功したときだけ新しいフォルダーへ公開します。

ファイル名から`.xdw`を除いた文字列が項目名になります。項目名のための注釈属性入力はありません。1フォルダーが1様式で、直下のXDWのみをファイル名順に読み込みます。各XDWは1ページ、回転0度、ページ直下の矩形がちょうど1個であり、ページ寸法は一式の最大値と最小値の差が縦横それぞれ0.1mm以内である必要があります。矩形は有限の正の面積を持ち、ページ内へ収めてください。

テンプレートの座標は左上を原点とし、右へX、下へYが増えるmmです。DocuWorks保存時は1/100mmへ四捨五入します。切り出しに使うpx座標は、対象ページの実際の画像寸法とページ実寸から計算します。画像化には補間・外周処理による小さな画素差があるため、元画像と背景XDWの画像が画素単位で同一になる保証はありません。

入力と以前の出力は上書きしません。処理中の原画像・編集用XDWの変更、既存の出力先、保存後の寸法や矩形の不一致はエラーです。SDKは短い専用一時パスで処理し、長い最終出力パスへは検証済みファイルをコピーします。
